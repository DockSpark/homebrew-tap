# DockSpark Homebrew Tap

Install [DockSpark](https://dockspark.app/) with Homebrew:

```sh
brew install --cask dockspark/tap/dockspark
```

Upgrade DockSpark with:

```sh
brew upgrade --cask --greedy dockspark
```

The DockSpark application and release notes are maintained in the
[DockSpark repository](https://github.com/DockSpark/DockSpark).
